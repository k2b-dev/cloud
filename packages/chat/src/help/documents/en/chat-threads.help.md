A thread is a named strand in a chat, such as "Problems" in the chat "IT". Every chat with threads also has **General** for everything that fits no thread. Each thread keeps its own unread messages and its own draft.

## Open a thread {icon="hash"}

:::steps
1. Open the chat. On a wide screen its threads show below it in the list.
2. Choose a thread. You can also use the thread button next to the chat's name.
:::

:::reference
- **All threads** shows every message of the chat in one timeline. A small label below each message names its thread; select it to open the thread.
- What you write in **All threads** goes to **General**. A reply goes to the thread of the message you answer.
- On a phone, a chat with threads opens its list of threads first. The back arrow in a thread returns to that list.
- A thread with unread messages is bold and shows how many. A chat that is not open adds up the counts of its threads.
:::

## Reply with a quote {icon="arrow-back-up"}

:::steps
1. Point at the message and select **…** beside it, or right-click the message. On a phone, touch and hold the message, or swipe it to the right.
2. Choose **Reply**.
3. Write your reply and send it.
:::

The reply shows the original message as a quote. Select the quote to jump to the original. To cancel the reply, select **×** next to the quote above the field.

:::reference
- Shortcut: select a message with the arrow keys and press **R**.
- If the original message is deleted, the quote says so.
:::

## Create, rename, and archive threads {icon="settings"}

Only people who manage the chat create, rename, and archive threads.

:::steps
1. Select **New thread** below the chat's threads, or in the thread button next to the chat's name. In a chat without threads, open the chat's info, select **…**, and choose **New thread**.
2. Enter a name and, if you like, a description of one line.
3. Select **Create**.
:::

To rename or archive the open thread, select **…** at the end of its header. An archived thread stays readable under **Archived**, but nobody can write in it. Select **Restore** in the archived thread, or **Undo** right after archiving, to bring it back.

:::reference
- **General** cannot be renamed or archived.
- A thread name exists once per chat, also among archived threads.
- If creating a thread fails, your text stays in the dialog and you can select **Try again**.
:::
