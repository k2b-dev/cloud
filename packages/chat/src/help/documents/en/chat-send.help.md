You can send messages in a chat you belong to with **Write** or **Manage** access.

## Open a chat {icon="messages"}

:::steps
1. Open **Chat**.
2. Choose a chat from the list.
:::

:::reference
- On a phone, the list and the open chat are separate screens. Use the back arrow or your phone's back gesture to return to the list.
- A link to a message opens the chat at that message and highlights it briefly.
:::

## Write and send a message {icon="send"}

:::steps
1. Write your message in the field below the messages.
2. Choose **Aa** to show formatting when you need it.
3. Press **Enter** to send, or choose **Send message** on a phone.
:::

:::reference
- **Shift+Enter** starts a new line.
- On a phone, **Enter** starts a new line. **Send message** sends the message.
:::

## Check whether the message was sent {icon="check"}

:::reference
- **Sending:** A clock means Chat is sending the message.
- **Sent:** A check means Chat accepted the message.
- **Not sent:** Chat could not send the message. Choose **Retry** to send the same message again without creating a copy. To remove a message that Chat cannot send, select the message and choose **Discard message**. Later messages show a clock and wait until this message is sent or discarded. This keeps the order in which you wrote them.
:::
