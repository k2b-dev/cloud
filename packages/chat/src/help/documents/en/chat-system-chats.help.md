A resource discussion brings its messages together. Each item has its own thread. Container access controls the chat; you also need access to an item to read its thread.

## Find the chat {icon="messages"}

:::steps
1. Open **Chat** and expand **Discussions** at the end of the chat list.
2. Choose a container. **All threads** opens with messages from its items and the container itself.
3. Choose a thread to read just that item's messages.
:::

Only discussions with a chat appear here. An empty section explains when a chat appears. If the section cannot load, choose **Try again** beside the error.

The short list shows recent threads, unread threads, and the open thread within one page. Choose **All N threads** or **Browse all threads** to browse more. Use **Search threads** and the **Open**, **Done**, or **Unread** filters. Choose **Show more threads** for the next page.

On large screens, a separate thread column provides the same search and filters. On a phone, the back arrow in a thread opens the thread overview.

## Write about an item {icon="message-plus"}

You need **Edit** or **Manage** access to the container.

:::steps
1. Choose **Talk about an item** below the threads, in the thread picker, or on the overview.
2. Find and select the item in the element picker. Choose **Add**.
3. Write your message in the item's thread and send it.
:::

The thread's title and status come from the item. The owning app supplies a context line. Assigned people and exact event times appear only when the app includes them there. Choose **Open in … ↗** to open the item. If opening the thread fails, the error stays visible and you can try again.

A message written in **All threads** goes to the container itself. A reply goes to the thread of the message you answer. The label under each message shows where it belongs.

## See what changed {icon="history"}

When the app offers an activity feed, changes to items show as quiet lines between the messages, such as "Mara set the status to “In review”". An item's thread shows only its own changes; **All threads** shows the changes of the whole container, each with the item's label.

:::reference
- Three or more changes in a row become one line such as **4 changes to …**. Choose it to see each change.
- Changes never count as unread and never appear in the chat list.
- You see only changes to items you may open.
:::

## Manage access {icon="users"}

Change access in the container. Chat does not offer member editing, leaving, or manual thread names for these chats.

An address you cannot access shows **Thread unavailable**, without the item's title. Choose **Back to chats** to return to the list.
