Chat is for conversations with other people.

## Overview {icon="layout-grid"}

:::reference
- **Chats:** Chat shows the chats you belong to. Until you belong to one, it says that there are no chats yet.
- **Administration:** Administrators see the state of the chat service at `/admin/chat`.
:::
