Chat is for conversations with other people, notes for yourself, and channels you subscribe to.

## Start a chat {icon="message-plus"}

:::steps
1. Choose **New chat**.
2. Keep **Chat** selected and choose the people or service accounts for the chat.
3. Enter a name if you want one.
4. Choose **Start chat**.
:::

With a full account, you can also choose groups. As a guest, choose from people you already share a chat with.
These people must be direct members of a shared chat.

If a chat with exactly these people exists, choose **Open existing** to use it.
Choose **Create a new chat anyway** to start another one with the same people.

## Discover channels {icon="compass"}

:::steps
1. Choose **Discover channels** below **Channels**.
2. Use **Search channels** to find a channel by name or purpose.
3. Choose **Subscribe** beside a channel.
4. Choose **Subscribed** to open it.
:::

The channel appears under **Channels**, with its purpose below its name.
Use **Show more** to load more search results. If loading fails, choose **Try again**.
With **Read** access, you see **Only the editors write here.** instead of the message field.
Channels have no threads.

## Create a channel {icon="hash"}

Everyone in the chosen audience can read the entire history before subscribing.
Existing members keep their access when you change the audience.

:::steps
1. Choose **New chat** and then **Channel**.
2. Enter the channel's name and purpose.
3. Under **Discoverable by**, choose groups and their **Read** or **Write** access.
4. Review how many accounts can find the channel.
5. Choose **New channel**.
:::

If the operator allows it, you can choose **Everyone with a Cloud account**. This includes guests and service accounts.
If confirmation is missing, reopen **New chat → Channel** and choose **Try again** to resume the same request.

## If confirmation is missing {icon="refresh"}

If **Try again** appears, choose it to finish the same request. The people and name stay fixed so a lost response does not create a second chat.
After reloading this tab, open **New chat** again to resume the request.
Choose **Cancel** to discard the request and start over. Check the list first: the chat may already exist.
Closing the tab, or a browser that blocks tab storage, prevents recovery after a reload.

## Keep notes for yourself {icon="notes"}

Start a chat without choosing anyone else. Without a name, this chat is called **You**.
Use it as a notepad across your devices.

## Overview {icon="layout-grid"}

:::reference
- **Chats:** The list shows the chats you belong to, with the last message and time. Subscribed channels have their own **Channels** area.
- **Administration:** Administrators see the state of the chat service at `/admin/chat`.
:::
