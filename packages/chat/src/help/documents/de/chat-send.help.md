Du kannst in einem Chat, in dem du Mitglied bist, mit Zugriff **Schreiben** oder **Verwalten** Nachrichten senden.

## Chat öffnen {icon="messages"}

:::steps
1. Öffne **Chat**.
2. Wähle einen Chat aus der Liste.
:::

:::reference
- Auf dem Smartphone sind die Liste und der offene Chat getrennte Ansichten. Mit dem Zurück-Pfeil oder der Zurück-Geste deines Smartphones kehrst du zur Liste zurück.
- Ein Link zu einer Nachricht öffnet den Chat bei dieser Nachricht und hebt sie kurz hervor.
:::

## Nachricht schreiben und senden {icon="send"}

:::steps
1. Schreibe deine Nachricht in das Feld unter den Nachrichten.
2. Wähle **Aa**, wenn du die Formatierung anzeigen möchtest.
3. Drücke **Enter** zum Senden oder wähle auf dem Smartphone **Nachricht senden**.
:::

:::reference
- **Shift+Enter** beginnt eine neue Zeile.
- Auf dem Smartphone beginnt **Enter** eine neue Zeile. **Nachricht senden** sendet die Nachricht.
- Eine Nachricht darf höchstens 20.000 Zeichen haben. Ist sie zu lang, bleibt der Text mit einem Hinweis im Feld. Kürze ihn und sende ihn erneut.
:::

## Prüfen, ob die Nachricht gesendet wurde {icon="check"}

:::reference
- **Wird gesendet:** Eine Uhr zeigt, dass Chat die Nachricht sendet.
- **Gesendet:** Ein Häkchen zeigt, dass Chat die Nachricht angenommen hat.
- **Nicht gesendet:** Chat konnte die Nachricht nicht senden. Wähle **Erneut senden**, um dieselbe Nachricht erneut zu senden, ohne eine Kopie zu erstellen. Um eine Nachricht zu entfernen, die Chat nicht senden kann, wähle **Verwerfen** neben **Erneut senden**. Spätere Nachrichten zeigen eine Uhr und warten, bis diese Nachricht gesendet oder verworfen ist. So bleibt die Reihenfolge, in der du sie geschrieben hast.
- Wenn du Chat mit noch nicht gesendeten Nachrichten verlässt oder neu lädst, fragt dein Browser zuerst nach, weil diese Nachrichten beim Verlassen verloren gehen.
:::

## Cloud-Element teilen {icon="share"}

:::steps
1. Wähle **+** neben dem Eingabefeld und dann **Cloud-Element teilen**.
2. Suche das Element, zum Beispiel eine Aufgabe, eine Notiz oder eine Datei, und wähle es aus.
3. Schreib bei Bedarf ein paar Worte dazu und sende die Nachricht.
:::

:::reference
- Das Element erscheint als Karte in der Nachricht. Wähle die Karte, um das Element zu öffnen.
- Jede Person sieht nur, was sie sehen darf. Ohne Zugriff auf das Element zeigt die Karte **Element nicht verfügbar**, ohne Titel und Ort.
- Teilen gibt niemandem Zugriff auf das Element.
:::

## Sehen, was geteilt wurde {icon="share-2"}

:::steps
1. Wähle **Chat-Info** im Kopf des Chats.
2. Schau unter **Geteilt**. Dort stehen Links und Cloud-Elemente, die neuesten zuerst.
3. Wähle eine Art, zum Beispiel **Links** oder **Cloud-Elemente**, oder einen Thread, um die Liste einzugrenzen.
4. Wähle einen Eintrag, um zu seiner Nachricht zu springen.
:::

## Auf eine Nachricht reagieren {icon="mood-plus"}

:::steps
1. Öffne das Menü der Nachricht: Wähle **…** neben der Nachricht, oder halte die Nachricht auf dem Telefon gedrückt.
2. Wähle **Reaktion hinzufügen** und dann ein Emoji.
:::

:::reference
- Reaktionen stehen unter der Nachricht, mit der Zahl der Personen, die sie gewählt haben. Deine sind hervorgehoben.
- Wähle eine Reaktion unter einer Nachricht, um deine hinzuzufügen oder zurückzunehmen.
- Wer eine Nachricht lesen kann, kann auf sie reagieren, auch Leser eines Kanals, die dort nicht schreiben.
:::
