Open an app and select a tool in its left navigation. Click **Start** to run it.
Opening an app or switching tools never starts code automatically. **Stop** ends
the worker; **Restart** starts a fresh run.

Choose files with the tool’s controls. Files stay on your device; originals stay
unchanged. Downloads begin directly when the tool requests them. Browser download
settings still apply. In the CSV workshop, choose a CSV, inspect its preview,
choose output columns and a delimiter, then export. **Past exports** lists
previously saved results on this device.

If processing fails, check the displayed file error. Share the relevant error or
a suitable sample with the person maintaining the app. App help describes Kit;
each custom tool may have its own instructions.
