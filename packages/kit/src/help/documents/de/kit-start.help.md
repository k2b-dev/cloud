Öffne eine App und wähle links ein Werkzeug. Klicke auf **Starten**, um es
auszuführen. Öffnen und Werkzeugwechsel starten keinen Code automatisch.
**Stoppen** beendet den Worker; **Neu starten** beginnt einen frischen Durchlauf.

Wähle Dateien über die Bedienelemente des Werkzeugs. Sie bleiben auf deinem Gerät;
Originale bleiben unverändert. Downloads beginnen direkt, wenn das Werkzeug sie
anfordert. Die Download-Einstellungen deines Browsers gelten weiterhin. In der
CSV-Werkstatt wählst du eine CSV, prüfst die Vorschau, stellst Spalten und
Trennzeichen ein und exportierst. **Vergangene Exporte** zeigt lokal gespeicherte
Ergebnisse dieses Geräts.

Bei Fehlern hilft die angezeigte Dateimeldung. Gib die relevante Fehlermeldung
oder eine geeignete Beispieldatei an die Person weiter, die die App pflegt.
Diese Hilfe erklärt Kit; einzelne Werkzeuge können eigene Anleitungen haben.
