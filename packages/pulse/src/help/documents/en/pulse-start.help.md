Pulse collects metrics, events, and states in bases. The overview lists the bases
that you can access. Open a base to manage its sources.

## Connect a source {icon="route"}

:::steps
1. **Create a base:** Use one base for one product, environment, or business area.
2. **Connect a source:** Add a metrics endpoint or an HTTP ingest source.
3. **Check collection:** Open **Sources** for recent updates, errors, and scrape history. HTTP ingest sources provide API keys and an example request.
:::

Earlier dashboards and saved queries were removed with this update. Existing
view links show a notice with an action to open Sources. Pulse keeps collecting
every value from your sources.
