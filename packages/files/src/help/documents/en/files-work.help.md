Most file work happens from the toolbar, the item context menu, or the detail panel.

## Manage items {icon="user-cog"}

:::reference
- **Open and preview:** Folders open in the app. Images open in the lightbox; browser-previewable files can open inline or in a new tab.
- **Download:** Files download directly. Folders download as a tar archive.
- **Rename, duplicate, or move:** Rename and duplicate stay in the current base. Move can target another accessible base from the move dialog.
- **Delete:** Delete moves items to Trash. The app prevents deleting from Trash.
:::

## Search and display {icon="search"}

:::reference
- **Folder search:** The folder search filters the current directory by name and keeps the filter in the URL.
- **Global search:** The Search page uses glob patterns such as `**/*.pdf` and can include hidden files or folders.
- **Panel settings:** Switch between list and grid, choose list columns, show hidden files, and enable precise file sizes.
:::

:::success Precise sizes can be slower
Precise file sizes are computed server-side for the selected directory. Enable them when you need totals, and turn them off for faster browsing.
:::
