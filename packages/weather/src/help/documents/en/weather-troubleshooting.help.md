## Common symptoms {icon="lifebuoy"}

:::reference
- **City search finds nothing:** Search currently covers German cities. Try the official city name and choose one of the returned results.
- **The forecast is unavailable:** The provider may have no data for the saved coordinates or may be temporarily unreachable. Retry later before removing the location.
- **Conditions look wrong for the street:** A city forecast represents the saved coordinates and cannot reflect every local microclimate.
- **A display looks stale:** Confirm that the device is online and allow the automatic refresh. Reload after the configured cache duration when needed.
- **The wrong location opens first:** Weather opens the first saved location. Use the location navigation to choose another city.
- **A location disappeared:** Saved locations belong to the signed-in user. Confirm that you are using the same account and Cloud environment.
:::

## Reset a saved location {icon="point"}

Remove and add the city again only when its saved coordinates or name are incorrect. Recreating the same location does not resolve a temporary provider error.
