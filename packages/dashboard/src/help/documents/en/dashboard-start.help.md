Dashboard is your personal start page and overview across Cloud. It combines app widgets you can access with shortcuts you choose, so help and customization are available before you open any individual app or record.

## Overview {icon="layout-grid"}

:::reference
- **Widgets:** Apps can publish dashboard widgets. The dashboard fetches the visible widgets for your current access level.
- **Shortcuts:** Shortcuts can point to a Cloud app or to a custom relative, HTTP(S), or mailto link.
- **Personal settings:** Hidden widgets, shortcuts, and greeting color are saved to your account.
:::

## Customize {icon="settings"}

:::reference
- **Widgets:** Use Edit dashboard to show or hide widgets. Widgets you cannot access are listed separately in the edit dialog.
- **Shortcuts:** Add app shortcuts or custom links from the shortcut section in the edit dialog.
- **Name color:** Choose the gradient used for your name in the greeting.
- **Open the source:** Select a widget or shortcut to continue in the owning app when the card provides a link.
:::

:::info Settings scope
Dashboard settings require a user-backed session. They are stored per user and reused on other devices after login.
:::
