Die Übersicht, die Seitenleiste und das Menü am Telefon verwenden dieselben Gruppen: **Bilder**, **Dokumente**, **Text und Codes**, **Sicherheit** und **Netzwerk**. Unter **Oft gebraucht** findest du vier Abkürzungen. In der Suche kannst du einen Werkzeugnamen, eine Kategorie, eine Beschreibung oder einen verwandten Begriff eingeben.

## Vom Ziel zum passenden Werkzeug {icon="category"}

| Ziel | Werkzeug | Ergebnis |
| --- | --- | --- |
| E-Mail-Link vorbereiten | **E-Mail-Link** | Ein Link mit Empfängern, Betreff und Text |
| QR-Code erstellen | **QR-Code** | Ein QR-Code für einen Link, WLAN-Zugang, Kontakt oder Text |
| Zufällige IDs erzeugen | **UUID** | Eine oder mehrere UUIDs |
| Platzhaltertext einfügen | **Blindtext** | Wörter, Sätze oder Absätze |
| Text kodieren oder dekodieren | **Text kodieren** | Text, umgewandelt zwischen den gewählten Kodierungen |
| Farbwert umrechnen | **Farben** | HEX-, RGB- und HSL-Darstellungen |
| Dokument extrahieren | **Dokument zu Markdown** | Lesbarer Dokumenttext als reines Markdown |
| Markdown drucken | **Markdown zu PDF** | Ein gestaltetes A4-PDF mit Vorlage und optionalem eigenem CSS |
| Prüfsumme berechnen | **Prüfsumme** | SHA-256- oder FNV-1a-Ausgabe |
| Zugangsdaten erstellen | **Passwort** | Ein zufälliges, merkbares oder PIN-artiges Passwort |
| Text schützen oder wiederherstellen | **Text verschlüsseln** | Daten für Ver- und Entschlüsselung mit AES-GCM oder ECDH |
| Bilder im Stapel konvertieren | **Bilder umwandeln** | JPEG, PNG, WebP oder Base64-HTML mit gemeinsamen Größeneinstellungen |
| Bild aufbereiten | **Foto bearbeiten** | Ein zugeschnittenes, angepasstes, beschriftetes, geschwärztes oder exportiertes Bild |
| Internetverbindung prüfen | **Speedtest** | Messwerte für Download, Upload, Ping und Jitter |
| HTTP-Verkehr untersuchen | **Webhook-Tester** | Ein empfangender Endpunkt, Anfrageverlauf und Testantworten |

:::info In der Übersicht beginnen
Jedes Werkzeug findest und öffnest du über die Übersicht. Suche nach einer Aufgabe oder einem Format und öffne das passende Werkzeug. Die Suche bleibt beim Neuladen oder bei der Rückkehr über „Zurück“ erhalten. Ohne Treffer setzt du sie mit **Suche zurücksetzen** zurück. Nach dem Öffnen bleibt die Seitenleiste verfügbar. So wechselst du direkt zwischen verwandten Werkzeugen, ohne zur Übersicht zurückzukehren.
:::
