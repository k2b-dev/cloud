Die Tools-Übersicht gruppiert die Werkzeuge danach, was du erreichen willst. Die Suche akzeptiert Werkzeugnamen, Kategorien, Beschreibungen oder verwandte Begriffe.

## Vom Ziel zum passenden Werkzeug {icon="category"}

| Ziel | Werkzeug | Ergebnis |
| --- | --- | --- |
| E-Mail-Link vorbereiten | `Mailto-Link` | Ein Link mit Empfängern, Betreff und Text |
| QR-Code erstellen | `QR-Code` | Ein QR-Code für einen Link, WLAN-Zugang, Kontakt oder Text |
| Zufällige IDs erzeugen | `UUID` | Eine oder mehrere UUIDs |
| Platzhaltertext einfügen | `Lorem Ipsum` | Wörter, Sätze oder Absätze |
| Text kodieren oder dekodieren | `Base64 / Hex / Base32` | Text, umgewandelt zwischen den gewählten Kodierungen |
| Farbwert umrechnen | `Farbkonverter` | HEX-, RGB- und HSL-Darstellungen |
| Dokument extrahieren | `Dokument zu Markdown` | Lesbarer Dokumenttext als reines Markdown |
| Markdown drucken | `Markdown zu PDF` | Ein gestaltetes A4-PDF mit Vorlage und optionalem eigenem CSS |
| Prüfsumme berechnen | `Hash-Generator` | SHA-256- oder FNV-1a-Ausgabe |
| Zugangsdaten erstellen | `Passwort-Generator` | Zufälliges, merkbares oder PIN-artiges Passwort |
| Text schützen oder wiederherstellen | `Verschlüsselung` | Daten für Ver- und Entschlüsselung mit AES-GCM oder ECDH |
| Bilder im Stapel konvertieren | `Bildkonverter` | JPEG, PNG, WebP oder Base64-HTML mit gemeinsamen Größeneinstellungen |
| Bild aufbereiten | `Bildbearbeitung` | Zugeschnittenes, angepasstes, beschriftetes, geschwärztes oder exportiertes Bild |
| Internetverbindung prüfen | `Internet-Speedtest` | Messwerte für Download, Upload, Ping und Jitter |
| HTTP-Verkehr untersuchen | `Webhook-Tester` | Ein empfangender Endpunkt, Anfrageverlauf und Testantworten |

:::info Starte in der Übersicht
Suche nach einer Aufgabe oder einem Format und öffne das passende Werkzeug. Die Seitenleiste bleibt anschließend verfügbar, sodass du direkt zwischen verwandten Werkzeugen wechseln kannst.
:::
