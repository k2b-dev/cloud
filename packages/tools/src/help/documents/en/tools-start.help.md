Tools is a workspace for small generators, encoders, security utilities, media tools, and network tests. You can find every tool in the overview before you open one.

## Find and use a tool {icon="route"}

:::steps
1. Open the tool from the overview, a group in the sidebar, or the tool search.
2. Enter the smallest input that you need. Most tools update their output from the values on the page.
3. Copy or download the result, where the tool offers it.
:::

Check where your data goes. Browser-local tools keep the data in the page. Document conversion, PDF rendering, and the network tools call the server, because they need server-side processing or a stable endpoint.

## Know the tool groups {icon="book-2"}

:::reference
- **Generators:** Mailto links, QR codes, UUIDs, lorem ipsum text, and passwords.
- **Encoders:** Base64, Hex, Base32, color conversion, text extraction from documents on the server, and Markdown-to-PDF rendering.
- **Security:** Hash generation, password generation, and encryption.
- **Media:** Bulk image conversion, and detailed resize, crop, filter, rotate, markup, and export.
- **Network:** Speed tests against the Cloud server and tests of webhook endpoints.
:::

:::info Webhook tester data
The server stores webhook endpoints and request logs so that you can inspect them. The tester redacts sensitive headers such as Authorization and Cookie before it logs a request.
:::
