The overview, sidebar, and phone menu share five groups: **Images**, **Documents**, **Text and codes**, **Security**, and **Network**. **Used often** offers four shortcuts. In the search, you can enter a tool name, a category, a description, or a related term.

## Match the task to a tool {icon="category"}

| Goal | Tool | Result |
| --- | --- | --- |
| Prepare an email link | **Email link** | A link with recipients, subject, and body |
| Make something scannable | **QR Code** | A QR code for a link, Wi-Fi access, contact, or text |
| Create random identifiers | **UUID** | One or many UUIDs |
| Add placeholder copy | **Placeholder text** | Words, sentences, or paragraphs |
| Encode or decode text | **Encode text** | Text converted between the selected encodings |
| Translate a color value | **Colors** | HEX, RGB, and HSL representations |
| Extract a document | **Document to Markdown** | Readable document text as plain Markdown |
| Print Markdown | **Markdown to PDF** | A styled A4 PDF with a preset and optional custom CSS |
| Calculate a digest | **Checksum** | SHA-256 or FNV-1a output |
| Create a credential | **Password** | A random, memorable, or PIN-style password |
| Protect or recover text | **Encrypt text** | AES-GCM or ECDH encryption and decryption data |
| Convert a batch of images | **Convert images** | JPEG, PNG, WebP, or Base64 HTML with shared size settings |
| Prepare an image | **Edit photo** | A cropped, adjusted, annotated, redacted, or exported image |
| Check this connection | **Speed test** | Download, upload, ping, and jitter measurements |
| Inspect HTTP traffic | **Webhook Tester** | A receiving endpoint, request history, and test responses |

:::info Start from the overview
You can find and open every utility from the overview. Search for a task or a format, and open the matching tool. The search stays in place after reload or Back. If nothing matches, choose **Clear search**. After you open a tool, the sidebar stays available. You can then move between related tools without a return to the overview.
:::
