The Contacts overview is a working view, not only a list of books. Search all books that you can access before you decide which book to open.

## Find the right contact {icon="search"}

:::reference
- **All contacts:** Searches the books that you can access and shows the book name next to each result.
- **Book view:** Open one book to use its tags, add a contact, review duplicates, or change the book settings.
- **Search:** Finds a name, company, email address, or phone number. Clear the search to return to the current book or the overview.
- **Tags:** Filter by the tags that the current scope shows. Tags belong to a book, so the same label in two books stays two separate tags.
- **Favorites:** Mark the contacts that you use often, then switch the overview to **Favorites**.
:::

## Work in the detail panel {icon="route"}

:::steps
1. Select a row to open the contact. The list keeps its position.
2. Choose **Email** or **Call** to use a primary contact point, if the contact has one.
3. Choose **Quick edit** for common fields, or **Edit all fields** for the complete contact form.
4. Add a comment for lasting context that belongs to the contact.
5. Use the action menu to move, duplicate, or delete the contact, if these actions are available.
:::

You can edit or delete your own comment for 10 minutes after you post it. You cannot change the comments of other people, even with **Manage** access to the book.

## Enter addresses and plan routes {icon="map-pin"}

Choose **Edit** beside an address to open its form in the contact workspace.
**Save** and **Cancel** return to the contact with your search and filters intact.
Reloading keeps the selected address but replaces unsaved input with saved values.

On desktop, **All**, **Favorites**, and search filter the contact list while keeping your open address and unsaved input. Close the editor to return to the full list tools.
If someone changed the contact before you saved, copy any changes you want to keep,
choose **Reload contact**, and apply them to the current version.

:::reference
- **Suggestions:** Type at least 3 characters in **Street and number**. Choose a suggestion to fill the street, postal code, city, and country. You can change each field after that.
- **Own entry:** Keep the text as you typed it. Choose the own entry in the list, or press Escape.
- **Country:** Enter the country name in the page language or its two-letter code, such as **Germany** or **DE**.
- **Location:** A chosen suggestion saves the location of the address. If you change the address later, Cloud looks up the location again. Cloud also looks up addresses without a location when you open the contact.
- **Map and route:** The contact shows a small map below the address. **Plan route** opens the maps app of your device.
- **No map:** If the map is not set up, or if the map budget is used up, the address stays without a map. **Plan route** then uses the address text.
:::

## Keep contacts useful {icon="table"}

- Put the most useful email address, phone number, website, or address first.
- Use book tags for repeating categories. Use the hierarchy only for lasting relationships between a parent and its members.
- Review exact duplicates in a book before you import another copy.
- Move a contact only when it belongs in another book. Links that would cross books cannot stay.

## Find a missing contact {icon="lifebuoy"}

- Clear the search, tag, favorite, and sort filters.
- Check whether you search **All contacts** or one specific book.
- Check that you still have access to the book.
- After an import, open the target book and review the import result or the duplicates before you import the file again.
