The Contacts overview is a working view, not only a list of books. Use it to search all readable books before deciding which book to open.

## Find the right contact {icon="search"}

:::reference
- **All Contacts:** Searches across the books you can read and shows the book name beside each result.
- **Book view:** Open one book when you want to use its tags, add a contact, review duplicates, or change book settings.
- **Search:** Match a name, company, email address, or phone number. Clear the query to return to the current book or overview.
- **Tags:** Filter by the tags visible for the current scope. Tags belong to a book, so the same label in two books remains separate.
- **Favorites:** Mark contacts you use often, then switch the overview to Favorites.
:::

## Work from the detail panel {icon="route"}

:::steps
1. Select a row to open the contact without losing the list position.
2. Use **Email** or **Call** for a primary contact point when one exists.
3. Open **Quick edit** for common fields or **Edit** for the complete contact form.
4. Add a note for durable context that belongs with the record.
5. Use the action menu for moving, duplicating, or deleting when those actions are available.
:::

You can edit or delete your own note for 10 minutes after posting. Other people's notes remain unchanged, including for contact-book administrators.

## Keep records useful {icon="table"}

- Put the most useful email address, phone number, website, or address first.
- Use book tags for repeatable categories and hierarchy only for durable parent/member relationships.
- Review exact duplicates inside a book before importing another copy.
- Move a contact only when it belongs in another book; links that would cross books cannot be kept.

## When a contact is missing {icon="lifebuoy"}

- Clear search, tag, favorite, and sort filters.
- Check whether you are searching All Contacts or one specific book.
- Confirm that you still have read access to the book.
- After an import, open the target book and review the import result or duplicate view before importing the file again.
