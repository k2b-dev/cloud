Die Kontaktbuch-Einstellungen steuern Name, Beschreibung, Tags, Zugriff, API Keys, Import, Export und Löschen eines Kontaktbuchs. Öffne sie mit der Einstellungsaktion neben einem Kontaktbuch in der Kontakte-Seitenleiste. Auf Mobilgeräten bleibt diese Aktion neben den Kontaktbüchern sichtbar, auf die du Zugriff **Verwalten** hast.

Auch Cloud-Administratoren sehen ein Kontaktbuch in Kontakte nur mit Zugriff; **Administration → Kontakte** zeigt jedes Kontaktbuch und seinen Zugriff.

## Kontaktbuch-Einstellungen finden {icon="settings"}

:::reference
- **Kontaktbuch → Allgemein:** Benenne das Kontaktbuch um und bearbeite seine optionale Beschreibung.
- **Kontaktbuch → Tags:** Erstelle, bearbeite und lösche die Tags dieses Kontaktbuchs. Zuweisen kannst du sie im Kontakteditor.
- **Freigabe → Zugriff:** Wähle **Zugriff bearbeiten**, um Personen und Gruppen Zugriff **Ansehen**, **Bearbeiten** oder **Verwalten** zu geben. Kontakte übernimmt deine Änderungen am Zugriff, wenn du **Speichern** wählst.
- **Freigabe → API Keys:** Erstelle Schlüssel für Integrationen, die ausschließlich auf dieses Kontaktbuch zugreifen sollen.
- **Daten → Import und Export:** Prüfe die Vorschau und importiere Kontakte aus einer vCard-Datei oder exportiere das Kontaktbuch als vCard oder CSV. Diese Aktionen brauchen Zugriff **Verwalten**.
:::

## Die Zugriffsstufe wählen {icon="lock"}

:::reference
- **Ansehen:** Kontakte ansehen.
- **Bearbeiten:** Zusätzlich Kontakte anlegen und aktualisieren.
- **Verwalten:** Zusätzlich die Einstellungen öffnen, das Kontaktbuch teilen, seine Tags bearbeiten, importieren, exportieren und das Kontaktbuch löschen.
:::

Ein Kontaktbuch behält immer mindestens eine Person, Gruppe oder einen Agenten mit Zugriff **Verwalten**; ein API Key zählt nicht.

Wer eigenen Zugriff hat, direkt, über eine Gruppe oder als angemeldete Person, sieht in den Details eines Kontakts unter **Mehr zu diesem Kontakt** › **Zugriff**, wer Zugriff auf das Kontaktbuch hat und mit welcher Stufe. Wer ein öffentliches Kontaktbuch nur liest, sieht diese Liste nicht.
