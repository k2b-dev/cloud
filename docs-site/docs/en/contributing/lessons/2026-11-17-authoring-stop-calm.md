### A paused authoring turn overstated costs and blurred drafts with versions

- **What happened:** Gustav's stop card said further attempts would cost too much and called a draft saved while saving a version remained open. Its new render test passed alone but broke neighboring page tests in CI: their HTML no longer contained the workspace island wrapper.
- **Root cause:** App messages interpreted the input-token allocation as a cost decision and used the same saving language for working drafts and submitted versions. The new test also registered a generic Solid compiler with process-wide `Bun.plugin`; when loaded first, it bypassed the neighboring tests' island-aware SSR compiler.
- **Error class:** Misleading status presentation across distinct persistence stages; process-wide test compiler contamination hidden by isolated file runs.
- **Guard:** `AssistantAuthoringStop.render.test.ts` covers every stop reason in German and English across absent, open, submitted, and mixed drafts, checking the title, reason, saved state, and checklist without cost claims. Shared-process Assistant render tests use the same `createConfig` plugin from `@k2b/ssr`. Run this test together with the frontend and PWA `page.render.test.ts` files in both orders, preloading the component test's compiler setup to force it to load first: the page tests require the workspace island wrapper. Bun can ignore command-line file order, so reversing arguments alone does not prove both compiler registration orders. This plugin convention has no static repository check yet.
