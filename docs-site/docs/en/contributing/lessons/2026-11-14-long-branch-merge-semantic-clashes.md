### A long-lived branch merges cleanly and still breaks the other side

- **What happened:** `feat/capability-blocks` (34 commits, six days old) merged onto `feat/code` with eighteen textual conflicts, and every package typechecked afterwards. Integration suites against the merge still found seven defects: a JSONB subtraction that bound to a call id and failed every Code version list, pending action arguments parsed twice, the choice history read twice per chat stream admission and once per live message (15 instead of 13 statements), approval edits that could not reach shared drafts in the frozen room, a NUL in an approval sentence, response schemas that JSON Schema could not project, and tests on both sides that encoded the other side's old contract. The first gate run then failed in 15 jobs: the source branch had never had a CI run, so its own old-contract tests, a Chat island 176 KB over budget, a runner image missing a newly imported file, Grids tables with multiple-choice cells, and pending approvals read in their storage form had never been checked.
- **Root cause:** Each branch was green only against its own base, and the source branch was never green at all. Behaviour that lives in SQL fragments, statement budgets, storage forms, bundle closures, image copy lists and published schemas is invisible to the type checker, and the branch had never run the other side's integration suites.
- **Error class:** Semantic merge clash between long-lived branches.
- **Guard:** Before porting a branch, check that it has a green `gate` run; if it has none, run the gate's jobs first. Before opening a pull request that merges a long-lived branch, run every integration file that imports a changed path (`git grep -l` over `*.integration.test.ts`) against isolated `_test` containers, plus the SQL budget tests of the hot paths it touches (`scripts/fixtures/sql-meter.ts`), the bundle budget tests of the islands that import changed modules, and `docker build` for every image that copies changed sources. After pushing, wait for the gate before reporting. The admission budget test in `packages/cloud/src/ai/routes.integration.test.ts`, the projection checks in `packages/cloud/src/_internal/capability-reviews.test.ts` and `packages/chat/src/frontend/ChatWorkspace.bundle.test.ts` caught the quiet regressions here.
