### A reactive editor extension dispatched during the view update and switched off the Yjs binding

- **What happened:** In the k2b notes SPA, a factory passed to `editor.use(() => …)` read a signal that changes while typing. The note's store is rewritten synchronously in the chain CodeMirror update → yCollab → Y.Doc update → store. The slot's effect then dispatched its reconfiguration in the middle of that update. CodeMirror reported "plugin crashed: Calls to EditorView.update are not allowed while an update is in progress" and switched the plugin off, here the Yjs sync. Further typing no longer reached the shared text until the next reconnect.
- **Root cause:** `use()` in `packages/editor/src/editor-state.ts` dispatched each new factory value synchronously from a Solid effect. A signal written by a view plugin runs that effect inside CodeMirror's update, where dispatching is not allowed.
- **Error class:** A host-facing reactive binding dispatches to CodeMirror from an effect that a signal written during the editor update can trigger (same family as `2026-10-30-editor-listener-read-subscribed-host-effect`).
- **Guard:** Slots store their new value at once and reach the view together one microtask later, after the update finished. `building-blocks.behavior.test.tsx` › "a factory that reads a signal written during an editor update leaves the writing plugin running" fails without the fix.
