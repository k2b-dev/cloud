### A late Plex face narrowed the buttons of a head already shown

- **What happened:** The dashboard's head buttons got 11 px narrower once after the page appeared (S2, CLS 0.000025).
- **Root cause:** Core served the `@k2b/ui` Plex preset with Fontsource's `font-display: swap` unchanged. Cloud preloads the Latin Sans faces, but a preload does not hold the first frame. When a face arrived after it, the browser replaced the fallback on the page already shown, and every word changed its width.
- **Error class:** A web font that may swap in after the first frame lets the network decide the layout. The same words have one width before the font arrives and another after.
- **Guard:** `packages/core/scripts/font-assets.ts` builds Cloud's `fonts.css` with `font-display: optional` for every face, the Condensed ones included, and fails the build when a face has another value. The `@k2b/ui` preset keeps `swap`: without a preload, `optional` would leave a first visit in the fallback font. Switching the preset would also have changed 31 browser tests in 11 packages that load it late and measure Plex. `packages/core/scripts/font-assets.browser.test.ts` serves Core's `fonts.css` with Cloud's preloads. When the faces are held back past the first frame, no head button changes its width (±0.5 px). When they arrive in time, the buttons show Plex. Cloud now preloads the Latin Sans 700 face too: sign-in and its locations set bold text in the first frame, and under `optional` a face without a preload stays in the wider fallback on a first visit, which cut their rows. Fixtures that build Core's `fonts.css` and measure Plex text preload the faces as Cloud does, with `plexPreloads()` from `packages/ui/test/plex-preloads.ts` (testing.md).
