### Chat shell geometry does not depend on button color transitions

- **What happened:** The dark phone shell test failed before measuring its server-rendered frame, including in the release merge group for #2717.
- **Root cause:** The test used page-wide animation settlement as its geometry readiness condition. Shell buttons could start finite color transitions during that wait, which `settled()` correctly rejects even though those transitions do not change the conversation frame.
- **Error class:** A browser test waits for unrelated visual activity instead of the observable state its assertion needs.
- **Guard:** `ChatWorkspace.shell.browser.test.ts` waits for the visible composer and loaded fonts before measuring the server frame. It retains the immediate first-client geometry comparison, phone and desktop layout assertions, and successful send checks. The `settle-reads` repository check requires an explicit readiness condition before geometry reads; reviews must choose a condition that belongs to the assertion.
