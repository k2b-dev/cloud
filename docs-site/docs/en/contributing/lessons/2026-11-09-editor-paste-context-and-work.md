### Editor transformations lost content and repeated unrelated work

- **What happened:** HTML paste merged paragraphs and list items, interpreted literal characters as Markdown, and paused editing after an unrelated edit during sanitizer loading. Slash actions opened inside code. Numbered-list formatting repeated `1.`, and converted paste did not scroll to the caret. Long notes rebuilt thousands of decorations for one keystroke.
- **Root cause:** Clipboard conversion assumed direct block children and emitted unescaped text. Blanket escaping then damaged URL tokens and conflicted with math delimiters. Deferred paste compared immutable document snapshots instead of mapping the original target. Slash completion omitted the code-context guard. Markup checked all code ranges for every node, and markup and lists rebuilt unchanged blocks. Incremental decoration must remember the last decorated selection across pointer holds, treat blank space as a local range, and filter bulk changes together. Formatting used a constant prefix and paste omitted its scroll request.
- **Error class:** Editor transformations ignore source structure, editing context or the actual region affected by a change.
- **Guard:** `text-editor-paste.behavior.test.ts` checks explicit Markdown against source fixtures and structural edge cases, literal punctuation and URLs; `clipboard-loading.browser.test.ts` delays the sanitizer through edits, typing and invalidated targets; `text-editor-format.behavior.test.ts` checks numbering. `slash-menu.test.ts` checks literal code contexts. `typing-budget.test.ts` limits deterministic comparisons, decoration construction and bulk filtering; `incremental-decorations.test.ts` compares incremental state with a fresh parse, including pointer holds. `math-syntax.test.ts` keeps unclosed pasted delimiters from consuming later formulas.
