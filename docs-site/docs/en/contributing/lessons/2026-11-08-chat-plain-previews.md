### Chat previews showed Markdown marks, and a settings hint's icon sat above its text

- **What happened:** The chat list, the side panel, For you, reply quotes, live list updates and push texts showed a message as written, so `hi **wie geht** es dir?` kept its asterisks. In a chat's Info, the settings icon of the hint "Browser, email, and quiet hours: Settings › Notifications" sat above the text line.
- **Root cause:** `messagePreview` only collapsed whitespace in the Markdown source, and two integration tests asserted raw `**…**` previews. The sidebar's SQL also folded every line break into a space before the preview was made, so a list or table could never read as plain text there. The hint was a hand-built flex row whose small text button kept its own height and padding, so the text line moved down while the icon stayed at the top.
- **Error class:** Showing stored source (Markdown) where a reader expects rendered text; a database-side bound that changes the meaning of the text it bounds; hand-built icon and text rows next to a shared inline pattern.
- **Guard:** `system-messages.test.ts` checks that previews contain only visible text; `snapshot.integration.test.ts` checks that the SQL-bounded sidebar preview of lists, tables, headings and code equals the preview of the whole message. The hint uses `InlineGuidance` from `@k2b/ui`, and `ChatNotifications.browser.test.ts` measures that the icon's middle and the text's middle agree within 1 px.
