### Editor UI followed the selection instead of the person: marks on open, raw blocks after blur, a returning bubble menu, a stale caret

- **What happened:** Opening a note showed the heading mark before its title, and an image, formula or table in the first lines showed its source, although nobody had clicked into the editor. After a click elsewhere, the block last edited stayed raw. The bubble menu came back after Escape as soon as a collaborator typed, and the others kept seeing a person's caret after focus had left the editor. A first fix that revealed source on focus missed the open case, because Notebooks focuses the editor itself when a note opens, and it reported every focus change as a transaction of its own, which moved the phone table sheet's handoff into a cell.
- **Root cause:** The Markdown decorations of `@k2b/editor` revealed source wherever `state.selection` stood, and CodeMirror's default selection at position 0 sits on the title line. `BubbleMenu` compared the dismissed selection by object identity, which every remote change replaces. `remoteCursors` cleared the published cursor only in a branch that required focus, which it never had there. A `focusChangeEffect` that returns an effect makes CodeMirror report the focus change in a separate later transaction instead of on the update that caused it. Clearing the cursor wrote the awareness inside an update, and a second editor that relays awareness redrew while its own update was still running, so CodeMirror switched the cursor plugin off.
- **Error class:** UI state derived from the selection or from focus alone, without asking whether the person acted, and without a value comparison that survives document changes; shared state written from inside an editor update.
- **Guard:** `reveal-focus.behavior.test.ts` checks for every preview extension that a block at the start stays rendered on focus, shows its source once the person acts and renders again on blur; `cursor-zone-field.behavior.test.ts` covers marks, a press, decorations added to a focused editor, and that taking focus adds no transaction. `note-preview.browser.test.ts` keeps the server preview equal to the mounted editor, also in write mode. `BubbleMenu.browser.test.ts` covers the menu after Escape; `collab.behavior.test.ts` covers the withdrawn caret with a listener that redraws on it.
