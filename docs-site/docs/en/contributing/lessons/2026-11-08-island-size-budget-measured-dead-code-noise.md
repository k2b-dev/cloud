### The /panel size budget measured naming noise from code it does not contain

- **What happened:** `panel.bundle.test.ts` failed for #2851 at 50,182 B against its 50,176 B budget, while main passed and the `/panel` islands had the same 63 inputs with the same bytes in the output (#2875). #2851 only changed `@k2b/ssr`'s mount runtime, which reaches the closure through `@k2b/ui`'s Button and `@k2b/ssr/nav` but contributes no byte to it.
- **Root cause:** Bun's minifier counts the uses in modules that tree shaking removes when it names the symbols of a shared chunk, and chunk hashes follow the content. Dead code therefore renamed a few identifiers in the Solid runtime chunk and changed chunk hashes, which moved the Brotli size by about 10 B with Bun 1.4.4 (up to 40 B in other builds). Main sits about 4 B under the budget, so any change to shared dead code could fail an unrelated pull request.
- **Error class:** A size budget measures noise from naming and hashing instead of the code it is about.
- **Guard:** `scripts/fixtures/island-bundle-size.ts` builds once, replaces every module that reaches no output with a stub that keeps its import edges and export names, and measures the second build: live code is compressed as built. `scripts/fixtures/island-bundle-size.test.ts` checks that dead code changing the unmeasured build gives the same size (±0) and that 1,000 incompressible bytes of live code show as 1,000 to 1,060 B.
