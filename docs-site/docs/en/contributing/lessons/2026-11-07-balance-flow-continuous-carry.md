### Carry balances through one continuous canvas

- **What happened:** Paging replaced one month's settlement diagram with another, hiding the connection between closing and opening balances.
- **Root cause:** Each period had its own layout and scale. Equal balances shared a colour but did not share a continuous band.
- **Error class:** A navigation model concealed continuity in the data.
- **Guard:** BalanceFlow layout tests compare the closing/opening edge, baseline, thickness and common scale at every boundary. The browser guard checks the newest month before scripts run, unchanged SVG after navigation, one normal-width shared balance node and combined accessible tooltip, no native titles, non-overlapping IBM Plex label boxes at 1440/1200 px, neighbour peeks on phones, compact 44 px amount rows with separators and a diagram-to-list gap of at most 10 px, longer-list scroll without frame growth, scroll inspection, both motion preferences and real state boxes.
- **Loading boundary:** Keep the specialized drawing out of the shared Sparkline host, and export table/size helpers from their own leaves. The Chat browser guard rejects an eager BalanceFlow renderer and compares the real card boxes before and after the first drawing download on desktop and phone. Assistant frames check the same geometry with only the public base stylesheet.
- **Bundle guard:** Keep table headings separate from navigation copy, imperative inspection mounting separate from its shared engine, and calendar sizing separate from drawing. The eager Chat graph rejects these drawing/mount modules; the existing island, prelude and per-kind ceilings stay unchanged. Calendar layout and SVG output retain their existing contract.
- **App-frame guard:** Compare the prelude module graph with main. BalanceFlow navigation, messages, table formatting and drawing belong to its hash-pinned lazy assets. Its controller receives the inspector already installed by the frame, avoiding a second inspection engine. The asset test rejects navigation/state/paint markers in the prelude, caps each paint/controller asset at 14,500 B, and checks that the controller imports no external modules. The offline browser test checks zero controller evaluations before drawing, one on first use, stable phone/desktop boxes and retry after a controller load failure. Shared number formatting remains identical for existing charts.
