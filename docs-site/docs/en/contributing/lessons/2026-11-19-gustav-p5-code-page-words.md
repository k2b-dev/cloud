### A placeholder target and fixed widths read as missing facts

- **What happened:** The P5 tour of the Gustav preview showed the Code page cutting off the next run ("Fr, 01.01.2027, 0…"), hiding the owner's own description behind a technical sentence, naming a place twice ("Spaces · Spaces") and counting "Letzte 1 Läufe · heute 1". A replaced version card claimed that the next approval "is further down" when nothing stood there.
- **Root cause:** The situation's first column was sized for dates of the current year. Personal Code's own chat is a placeholder target (`core.ai.chat` with id null), which the name resolver treats like a target chosen during the run, so the description stayed hidden even from the owner. The place of an app-wide grant is the app's name. The run caption had no singular form and repeated the count. The replaced card stated a place it cannot know.
- **Error class:** A rule or layout written for the common case does not cover a placeholder, a singular or a value from another year.
- **Guard:** `present.test.ts` covers the owner, another reader and a place's Code with the bound chat. `CodePage.render.test.tsx` covers the app-wide grant and the singular captions in both languages, and `AssistantCodeVersionCard.render.test.ts` covers the replaced card's quiet line. The situation's columns now hold a date in another year, with their sum unchanged so the strip stays in place.
