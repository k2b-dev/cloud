### The Code version card moved under the pointer and dropped keyboard focus

- **What happened:** After a step, the chat's Code version card fell back to its skeleton and then grew a status line above its switch, so the switch moved under the pointer. Switching on from the keyboard removed the focused switch and left focus nowhere. A waiting activation said "Core keeps trying", `code_run` chose its phase texts by locale prefix, and untitled schedules and events read by their stable identifiers in the card, the Code page runs and the administration.
- **Root cause:** `load()` reset the card to its loading state on every reload, the status was inserted on demand above the actions, and nothing moved focus when the switch disappeared. Text and names were built in each surface instead of one catalog and one naming function.
- **Error class:** A card replaces or inserts content around the control the person just used, and each surface names shared objects its own way.
- **Guard:** `packages/assistant/src/frontend/AssistantCodeVersionCard.behavior.test.tsx` fails when a reload shows the skeleton, when the actions row changes shape after a step, or when focus does not follow to the result. `messages.test.ts` fails on "Core" in Assistant text. `targets.test.ts` and `packages/core/src/code/automation-view.test.ts` pin the shared names and the strict preview shape; `code-runtime-tools.test.ts` reads `code_run` phases from their catalog.
