### The Notes browser test stopped reconnecting 2^31 ms after its pinned date

- **What happened:** From 24 November 2026, 08:31 UTC, the Notes browser sync integration test failed in CI on three unrelated pull requests and on every local run. After the server restart, neither browser reconnected within 5 s. The page set its 1 s reconnect timer, which never fired. The failure followed the calendar, not a code change ([#4099](https://github.com/k2b-dev/cloud/issues/4099)).
- **Root cause:** The test pinned the test process with `setSystemTime(NOW)` and each page with `page.clock.setFixedTime(NOW)`. Playwright's driver runs in the test process and stamps its clock commands with the pinned `Date.now()`, while the page replays them against the real time. The page's fake clock therefore starts at "today − NOW". After 24.8 days (2^31 ms) the fake timers stop firing.
- **Error class:** A browser test pins the page with Playwright's clock while the test process clock is faked, so the page's timers depend on the day the test runs.
- **Guard:** The test pins only `Date` with a page script (`pinPageClock`), and the page keeps its real timers. The `test-clock` check now also flags Playwright clock pins in `*.integration.test.ts` files, which it did not scan before. A minimal Playwright probe reproduced the stop at 2026-10-30 and showed that timers still fire at 2026-11-20.
