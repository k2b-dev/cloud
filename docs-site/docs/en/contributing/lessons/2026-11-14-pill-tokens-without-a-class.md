### Pill tokens without a pill class left the Lightbox pills uneven

- **What happened:** The `Lightbox` action pill was 40 px high with 3 px padding around a 28 px Open button: 6 px above and below it, 3 px at its side. Its zoom pill was an inline `Toolbar` with 44 px buttons, 46 px high, and the floating `Toolbar`, such as the Files selection pill, was 54 px. The Notebooks editor pills were 38 px with 7 px on every side.
- **Root cause:** The 10 November fix added the tokens `--k2b-pill-control` and `--k2b-pill-inset`, but every pill still set its own height, padding, radius and button size. A pill that never adopted the tokens, such as the Lightbox, kept its own sizes, and the floating `Toolbar` kept a second pair of tokens with a 44 px default.
- **Error class:** A shared visual pattern is shared only as tokens, so each instance must copy the geometry correctly by hand and can silently skip it.
- **Guard:** One public class, `k2b-pill`, in `@k2b/ui` owns the geometry: height, inset, round controls, icon and text size. The floating `Toolbar`, the `PdfViewer` bar, the Lightbox pills, the Notebooks pills and the Files preview pill use it. The browser tests measure every pill with one helper, `packages/ui/test/pill.ts`: 38 px, 7 px on every side, round controls (`lightbox.browser.test.ts`, `pdf-viewer.browser.test.ts`, `toolbar.browser.test.ts`). A new pill takes the class instead of its own sizes.
