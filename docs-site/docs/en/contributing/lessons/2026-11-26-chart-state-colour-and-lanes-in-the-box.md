### A state timeline drew a failed run orange and let its lane names leave the chart

- **What happened:** In gateway-ops (#4205), the runs timeline showed "Fehlgeschlagen" in orange, not in the red the app gave it. Below about 400 px, the lane names ran out of the chart on the left and the legend ran out on the right.
- **Root cause:** A region with its own colour also had a series class, and that class sets `fill` in CSS. A CSS rule wins over a `fill` attribute, so the series colour hid the state colour. The threshold bar gauge had the same pairing. The chart draws in 480 units that CSS stretches to the box, while text keeps its pixel size. So a lane name and the one-row SVG legend had a pixel width that the renderer could not know.
- **Error class:** An own colour and a series class on the same mark. Text placed in stretched drawing units, on the assumption that one unit is one pixel.
- **Guard:** `seriesPaint` gives a mark its own colour or the series class, never both. Lane names start at the left edge. A clip and a fade in drawing units bound them to the label column, so the cut scales with the box. `Chart` puts the states into its HTML legend, which wraps. `packages/ui/src/content/chart-state-timeline.browser.test.ts` checks at 1440 and 390 px, in Chromium and WebKit, that a state's colour fills its regions and its swatch, and that lane names end before the plot. It also checks that every legend entry stands whole in the chart.
- **Frozen drawings changed:** these drawings recorded the defect, so they change with the fix (see Chart renderer parity). In `legacy-svg.json`, eight state timeline cases and `barGauge-thresholds` lose the series class on a mark with its own colour. The timeline cases also get the clipped lane names, which read left to right in a page written right to left too. In `legacy-demo-svg.json`, demo drawing 17 (the state timeline) loses its SVG legend, since `Chart` shows the states in its HTML legend. The snapshot digest of the state timeline changes for the same reasons.
- **Found in review:** the ids of the clip came from the geometry, so two timelines of the same lanes shared them, and a hidden first one clipped nothing. `Chart` now gives each drawing ids of its own. A server-selected region took the series colour of its row; it now takes the colour the browser reads from the mark.
