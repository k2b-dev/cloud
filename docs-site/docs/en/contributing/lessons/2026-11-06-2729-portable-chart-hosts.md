### Bar charts depended on the component wrapper to remain drawable

- **What happened:** Category hit areas painted black in PDF and app frames, horizontal bars failed in app frames, Chat rejected stacked layouts, and dense grouped bars disappeared.
- **Root cause:** New marks relied on scoped component CSS, two consumers did not handle the additive description, and a fixed inner gap consumed narrow bars.
- **Error class:** A portable renderer is verified only through its component host, leaving transport, stylesheet, and geometry assumptions unchecked.
- **Guard:** `chart-bars-family.browser.test.ts` checks computed fills without the component wrapper and with only base CSS. `cloud-lib.test.ts` renders horizontal app-frame charts, `default-tools.test.ts` parses bar layouts, and bar-family tests check dense widths, missing totals, locale, headers, and bounded legends. The focused guard set also includes the base stylesheet contract, chart snapshot compatibility, view diagnostics and the offline frame size budget. Legacy bars retain their exact SVG and snapshot digest; new bands belong only to aligned series and horizontal bars. Validation still locates an empty limited bar at `data`. The offline frame keeps main’s size budget: a reference-only schema module prevents reference cells from loading capability and mail registration schemas.

Transparent hit areas must also be excluded when inspection reads a mark’s paint. The browser guard compares an old single-series bar’s server selection color with the client color, checks keyboard and controlled-selection outlines, and verifies that pointer hover paints only the category band. A stable horizontal legend budget keeps the renderer’s grown height equal to every consumer’s reserved height.

Kind registration belongs in the core registry; the component namespace and kind union derive from it. Horizontal renderers use the UI SVG helpers and core entry, avoiding framework dependencies in print and app-frame imports. Frozen pre-port parity compares complete legacy drawings without normalization. Old columns and rows retain their original anchors and use the inspector’s shared overlay.

First-render parity counts derive from the shared fixture registry, so adding a kind also extends the browser guard. Inspection titles are serialized and escaped once with their metadata. The pointer guard targets the center of rounded hit geometry: a fixed corner offset can fall outside a stretched SVG hit area. Calm-hover stroke suppression applies only to transient hover on renderers with their own bands; keyboard inspection and controlled selection retain their mark outlines.

Category legends use the inspector’s existing field/default metadata, keeping the published inspector below its unchanged 17 KB budget. Comparison hover rules include the nested previous-period rectangle. Host fixtures enable inspection before targeting a category, and fixed-height harnesses settle scrolling before pointer assertions.

Pointer-versus-keyboard paint belongs in the bar host styles through `:focus-visible`, without adding a second hover mode to the shared inspector. Compare and horizontal marks keep strokes in presentation attributes so the layered base stylesheet can override them without `!important`; every custom property read by that stylesheet has a definition. The existing stylesheet and packed-inspector guards cover these boundaries without exceptions or budget changes.

Chart view parsers share a module with other tool contracts. Side-effect-free schema factories let browser bundles omit unused card, survey, text-editor and shell schemas while preserving the public exports and validation. A parser bundle guard rejects their characteristic schema strings; the production island closure budgets remain unchanged.
