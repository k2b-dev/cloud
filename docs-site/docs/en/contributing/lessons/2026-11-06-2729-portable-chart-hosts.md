### Bar charts depended on the component wrapper to remain drawable

- **What happened:** Category hit areas painted black in PDF and app frames, horizontal bars failed in app frames, Chat rejected stacked layouts, and dense grouped bars disappeared.
- **Root cause:** New marks relied on scoped component CSS, two consumers did not handle the additive description, and a fixed inner gap consumed narrow bars.
- **Error class:** A portable renderer is verified only through its component host, leaving transport, stylesheet, and geometry assumptions unchecked.
- **Guard:** `chart-bars-family.browser.test.ts` checks computed fills without the component wrapper and with only base CSS. `cloud-lib.test.ts` renders horizontal app-frame charts, `default-tools.test.ts` parses bar layouts, and bar-family tests check dense widths, missing totals, locale, headers, and bounded legends. The focused guard set also includes the base stylesheet contract, chart snapshot compatibility, view diagnostics and the offline frame size budget. A new hit band changes the bar snapshot deliberately; validation still locates an empty bar at `data`. The prelude grows from 299.8 KB to 315.2 KB for the new drawings and validation, with the existing 10% headroom retained above that measured size.

Transparent hit areas must also be excluded when inspection reads a mark’s paint. The browser guard compares an old single-series bar’s server selection color with the client color, checks keyboard and controlled-selection outlines, and verifies that pointer hover paints only the category band. A stable horizontal legend budget keeps the renderer’s grown height equal to every consumer’s reserved height.

Kind registration belongs in the core registry; the component namespace and kind union derive from it. Horizontal renderers use the UI SVG helpers and core entry, avoiding framework dependencies in print and app-frame imports. Frozen pre-port parity still checks every painted bar node; only the intentional transparent hit bands and tooltip anchors are normalized, with separate category-inspection guards.
