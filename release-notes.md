## [0.8.0](https://github.com/k2b-dev/cloud/compare/cloud-v0.7.0...cloud-v0.8.0) (2026-09-21)


###   BREAKING CHANGES

* **grids:** Local calculation storage requires matching Grids code and schema. Startup backfills drafts transactionally; record writes must use Grids services. DATEADD supports input and output years 1000 through 9999.
* **commands:** unify context shortcuts and scoped Assistant search
* **grids:** make billing document creation nonblocking
* **workflows:** wake workers immediately and bound parallel runs
* **grids:** remove document parsing workflows
* **search:** add interactive commands and contextual actions
* **search:** Universal Search providers must use the updated canonical input schema. Deploy matching application images together; no stored-data migration is required.
* **cloud:** Remove the AppWorkspace SidebarMobile slots. Hosts now render mobile navigation from createNavigation; Cloud apps register their root navigation through WorkspaceNavigationProvider or its SSR island.
* **help:** Help corpus registry exports and inline runtime article lists are removed. Update Core and Help-producing applications together; Core setup creates the Postgres Help schema.
* **notifications:** deliver browser alerts exclusively through web push
* **grids:** use one fresh schema and runtime contract
* **assistant:** use one code mode UI API
* **grids:** cut obsolete alpha compatibility
* **ui:** unify chart exploration and comparison
* **mail:** replace the migration chain with one baseline schema
* **mail:** accept only password credentials for IMAP and SMTP
* migrate Cloud packages and releases to k2b-dev
* **sync:** Remove the syncOps registration API and qualify dead-letter mutations by resource kind. Stop old Cloud writers together and complete the documented snapshot and backfill checks before upgrading.
